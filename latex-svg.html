LaTeX Math to SVG

Type LaTeX math and export a standalone SVG for slides, posters, figures, and web pages. Supports AMS math, colors, and common macros. Delimiters like $...$ are optional — paste the expression body directly. Copy vector pastes a true vector graphic. Copy image uses a high-resolution PNG when vector clipboard is unavailable.
