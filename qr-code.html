QR Code Generator

Turn links into QR codes and download them as standalone SVG files for slides, posters, and print. Paste one link per line to generate several at once. Everything runs locally in your browser.

Add | KEYWORD after a link to add a keyword to its code. Links without a scheme (e.g. example.com) get https://.

Codes with a keyword use at least error correction Q so they stay scannable. Test the result with a phone.
No codes
Built for slides: fewer, larger modules scan from further away. Rule of thumb, a code scans from about 10× its own width (a 30 cm code on screen works at roughly 3 m). A shorter link means fewer modules.
